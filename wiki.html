Every colleague loses hours to work that requires no human judgement.

02 · The Solution

KAI is a personal PA for every colleague.

KAI connects to the tools colleagues already use — Gmail, Google Calendar, Google Drive — and brings the intelligence of a well-briefed PA to every interaction. Not generic AI. Organisational intelligence.

✓ Live
🌅

Morning Briefing

Every morning KAI reads your inbox and calendar and delivers a concise brief — today's meetings, urgent emails, clashes, wellbeing nudges, and timecode suggestions. Like arriving at your desk to find it all laid out.

✓ Live
📬

Smart Inbox Triage

Emails ranked by stakeholder importance — not just arrival time. URGENT items from Director level and above surface immediately. FYI noise is separated automatically. Never miss what matters.

✓ Live
✍️

Draft Reply Generation

One tap generates a professional, context-aware draft reply to any email — in your voice, not generic AI prose. You review and send. KAI drafts, humans decide.

✓ Live
📅

Calendar Intelligence

Clash detection, heavy day flagging, meeting prep sheets. KAI spots the 14:00 double-booking a PA would never allow, and can now create calendar events directly from email requests or chat commands.

✓ Live
💬

Ask KAI

Conversational interface with full inbox and calendar context. "What should I prioritise today?" "Show me emails from Marcus." "What are my open actions?" KAI answers from real data, not generic knowledge.

✓ Live
🗄️

Compliance Archive

Regulatory emails auto-detected and saved to Google Drive with a structured folder hierarchy — Governance, Regulatory, Projects, Stakeholder Correspondence. Audit trail built automatically.

✓ Live
📋

Meeting Prep Agent

Click any calendar event to open a prep sheet — KAI generates a meeting brief, talking points, and watch-outs. Related emails are surfaced. A multi-turn chat lets you go deeper before you walk in the room.

⚙ Deploy
📝

Open Actions Store

Persistent memory across sessions. "Remember I need to send the strategy paper by Friday" — KAI saves it to Google Drive, surfaces it in your briefing, and flags it as overdue if it passes without resolution.

Soon
🔍

Meeting Slot Suggester

When KAI detects a meeting request in an email, it finds 3 free gaps in your calendar and drafts a reply with those slots — ready to send with one tap.

Soon
📄

Meeting Minutes Ingestion

Paste a meeting transcript or upload notes. KAI extracts action items with owners and due dates, adds them to your Open Actions store, and reminds you if they go stale.

Future
🕐

Timecode Assist

KAI maps each calendar event to our project taxonomy automatically — PRJ-042, GOV-011, BAU-001 — and pre-fills your timesheet at end of week. Our codes, our context. No generic product will ever have this.

Future
✈️

Travel-aware Mode

When KAI detects a travel day, it adjusts its behaviour — no early morning slot suggestions, transit time blocked, travel-relevant emails surfaced. Context-aware, not just calendar-aware.

03 · Architecture

Built on open standards.
Deployable anywhere.

The demo runs on GitHub Pages with a Cloudflare Worker proxy. The production build moves the same architecture into Microsoft 365 — Copilot Studio, Azure OpenAI, Graph API — with full UK data residency and enterprise security controls.

System Architecture — Demo + Production
Demo · Frontend
GitHub Pages
Single-file HTML/JS. No build step. Deployable in minutes.
Demo · Proxy
Cloudflare Worker
Secure Anthropic API proxy. KV storage for persistent notes file ID.
Demo · LLM
Claude Sonnet 4.6
Anthropic API via Worker proxy. Draft replies, briefings, meeting prep.
Demo · Data
Google APIs
Gmail, Calendar, Drive — OAuth implicit flow. Real data, not mocked.
Production · Agent
Copilot Studio
M365-native agent builder. Graph API connectors. Teams deployment.
Production · LLM
Azure OpenAI GPT-4o
UK South data residency. Private endpoint. No cross-border transfer.
Production · Automation
Power Automate
8am scheduled briefing flow. Event-triggered replies. Approval chains.
Production · Security
Azure AD + Key Vault
Managed identity. No secrets in code. RBAC. Full audit trail.
04 · Roadmap

Four phases. Built to compound.

Each phase delivers standalone value and makes the next phase more powerful. Phase 1 is the foundation. Phase 4 is institutional memory — something that takes years to build and is impossible to replicate from scratch.

P1
Phase 1 · Now — Demo live, Production building
Foundation — Suggest, don't act
The minimum viable KAI. Inbox triage, daily Teams briefing, draft reply generation, unreplied email flagging. KAI suggests — humans decide. Every action is proposed, never taken autonomously.
Smart inbox triage Morning briefing Draft reply generation Compliance archive Meeting prep sheet Ask KAI chat
P2
Phase 2 · In progress — Features built, deploying
Org Intelligence — Context gets richer
KAI learns more about the organisation — stakeholder registry integration, calendar clash resolution, meeting slot suggestions, persistent action tracking across sessions, email-to-calendar intelligence.
Clash detection + highlighting Wellbeing nudges Open Actions store Calendar event creation Email intent detection Meeting slot suggester Stakeholder registry FYI weekly digest
P3
Phase 3 · Planned — Deep autonomy
Deep Autonomy — KAI acts on your behalf
With trust established, KAI moves from suggesting to acting. Auto-booking focus time and prep slots, timecode auto-assignment, travel-aware diary mode, wellbeing trend tracking.
Focus time auto-booking Prep time auto-booking Timecode auto-assignment Travel-aware mode Wellbeing trend tracking Draft reply tone matching
P4
Phase 4 · Vision — Institutional memory
Institutional Memory — The moat
KAI learns individual working patterns, energy mapping, deadline archaeology across years of email history. The longer it runs, the better it gets — and the harder it becomes to replace with a generic product.
Personal context model Energy mapping Deadline archaeology Noise filter + digest Org knowledge graph
05 · Benefits

What KAI actually changes.

The benefits split across three groups: individual colleagues who get their time back, managers who get better-prepared teams, and the organisation which gets accurate data and lower overhead.

01
🧠
Focus time back
Up to 77 hours per person per year returned to deep, valuable work — by removing inbox noise, eliminating calendar chaos, and surfacing only what actually needs attention.
02
⚖️
PA-level support for everyone
Senior leaders have always had administrative intelligence support. KAI democratises it across every grade — without headcount. The playing field levels at scale.
03
📊
Accurate organisational data
Timecodes logged accurately in real time. Meeting attendance patterns tracked. Wellbeing indicators surfaced before they become problems. Data quality improves as a side effect.
04
🛡️
Compliance by default
Regulatory emails automatically detected and archived. Governance deadlines surfaced before they're missed. Audit trail built automatically — not as an afterthought.
05
🔗
Organisational intelligence that compounds
The longer KAI runs, the more it knows about how the organisation works. Each phase builds on the last. By Phase 4 this is an institutional asset — not a tool.
06
✅
Governed, audited, human-approved
KAI operates on a suggest-don't-act principle in Phases 1–2. Every draft is reviewed. Every action is approved. Full audit log. This is responsible AI — not reckless automation.
